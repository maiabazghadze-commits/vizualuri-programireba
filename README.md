## 🚀 როგორ გავხსნათ და გამოვიყენოთ რესურსი?

1. რესურსი მუშაობს **ავტონომიურად**, ინტერნეტის ან დამატებითი ბიბლიოთეკების ინსტალაციის გარეშე.
2. უბრალოდ ორჯერ დააწკაპუნეთ `index.html` ფაილს, ან გახსენით ის ნებისმიერ თანამედროვე ბრაუზერში (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. მორგებულია როგორც კომპიუტერზე (ლეპტოპი/დესკტოპი), ისე პლანშეტსა და ინტერაქტიულ საკლასო დაფაზე.

## 🌟 რესურსის ძირითადი მოდულები

1. **🍳 ნაბიჯი 1: მაგიური რეცეპტი და „რობოტი შეფი“**
   - ყოველდღიური ცხოვრების ანალოგია (სენდვიჩის მომზადების თანმიმდევრობა).
   - ინტერაქტიული მინი-ექსპერიმენტი: რა მოხდება, თუ ბრძანებების რიგითობა აგვერევა?
2. **🧱 ნაბიჯი 2: რა არის ვიზუალური პროგრამირება?**
   - ტექსტური კოდის (რთული სინტაქსი, წერტილ-მძიმეები) და ვიზუალური ბლოკების (ლეგოს კუბიკები) შედარება.
   - 5 მთავარი ცნება: *ბრძანება, თანმიმდევრობა, ციკლი (გამეორება), პირობა, ბაგი (შეცდომა)*.
3. **🎮 ნაბიჯი 3: პლატფორმების ვიტრინა**
   - **Scratch**: სპრაიტები, კოსტიუმები, ფონები, მოძრაობა და ხმები.
   - **Code.org**: ლაბირინთები და ლოგიკური ამოცანების ნაბიჯ-ნაბიჯ ამოხსნა.
   - **Minecraft: Education Edition**: 3D სამყარო, რობოტი-აგენტი (Agent) და გუნდური შემოქმედება.
4. **🚀 ნაბიჯი 4: ინტერაქტიული ლაბორატორია („დაეხმარე რობოტ რობის!“)**
   - ბლოკების კონსტრუქტორი და 5x5 ლაბირინთის ცოცხალი სიმულატორი.
   - 3 დონე (საბაზისო, საშუალო და ⭐ „გამოწვევა ვარსკვლავით“ ციკლის გამოყენებით).
   - რეჟიმები: `▶ გაშვება`, `👣 ნაბიჯ-ნაბიჯ (დეტექტივი)`, `↺ თავიდან`.
   - მყისიერი, მეგობრული უკუკავშირი და კონფეტის ეფექტი წარმატებისას.
5. **🛡️ ნაბიჯი 5: ციფრული ეთიკა, უსაფრთხოება და ჯანმრთელობა**
   - პერსონალური მონაცემების ფარი (რა ინფორმაცია არ უნდა გაზიარდეს ონლაინ).
   - ციფრული ეთიკა და სხვისი ნაშრომის პატივისცემა (Remix & Credit).
   - თვალების დასვენების 20-20-20 წესი და ინტერაქტიული 20-წამიანი თვალის ვარჯიში.
6. **🏆 ნაბიჯი 6: თვითშეფასების სახალისო ქვიზი**
   - 4 ინტერაქტიული კითხვა მყისიერი განმარტებებითა და შემაჯამებელი შედეგებით.
